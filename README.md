 Calculadora Java
 Metodos
 sumar(a, b) suma dos números.
 restar(a, b) resta dos números.
 multiplicar(a, b) multiplica dos números.
 dividir(a, b) divide dos números 
 potencia(base, exponente) eleva la base al exponente.
 modulo(a, b) calcula el resto de la división 

Como ejecutar
mvn clean compile
java -cp target/classes es.daw.calculadora.Main
